# Achromatic React To-Do List

A small React application built as one of my first projects while learning React fundamentals, particularly `useState`, `useEffect`, controlled forms, and basic state management.

The project implements two simple sections—tasks and notes—with functionality for creating, editing, and deleting entries.

## Features

- Add, edit, and delete tasks
- Add, edit, and delete notes
- Controlled form inputs
- Form submission handling
- Native `<dialog>` elements for editing
- Expandable note sections using `<details>`
- Conditional rendering for empty states
- Responsive layout

## What I Practiced

This project was primarily a learning exercise for understanding how React manages UI state and user interactions.

### React

- `useState` for application and form state
- `useEffect` for side effects
- `useRef` for interacting with native DOM elements
- Controlled inputs
- Conditional rendering
- Rendering lists with `.map()`
- Updating array state immutably
- Functional state updates

### Forms

The project includes two approaches to handling user input:

- Direct event handling for adding tasks
- Form submission handling for adding and editing notes

This was intentional so I could practice different patterns for handling forms in React.

### UI

- Tailwind CSS for styling
- Lucide React for icons
- Native HTML `<dialog>` elements for edit modals
- Native `<details>` / `<summary>` elements for expandable notes

## Tech Stack

- React
- JavaScript
- Tailwind CSS
- Lucide React
- Vite

## Project Context

This was one of my first React projects and was created primarily for learning rather than as a production application.

The goal was to understand the fundamentals of React state, effects, forms, refs, and interactive UI before moving on to more complex projects.

## Getting Started

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local development URL provided by Vite.
